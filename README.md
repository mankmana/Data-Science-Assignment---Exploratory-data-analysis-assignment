# Exploratory Data Analysis Assignment

This repository contains the submission structure for both parts of the exploratory data analysis assignment.

## Submission contents

### Part 1 — EDA, visualization, preparation, and AutoML

Part 1 contains two dataset tracks:

- A diverse tabular dataset: Airbnb listings.
- A time-series dataset: Metro Interstate Traffic Volume.

Each track has space for detailed EDA, visualizations, cleaning, imputation, anomaly elimination, clustering, feature processing and selection, and AutoML experiments using AutoViML.

See [part-1/README.md](./part-1/README.md).

### Part 2 — Agentic data analysis

Part 2 contains the agent-assisted EDA workflow, prompts, generated artifacts, reports, screenshots, and slide-deck support materials.

See [part-2/README.md](./part-2/README.md).

## Video walkthroughs

The final submission must include detailed YouTube walkthroughs for both parts. Each video should explain the code snippets, analysis decisions, outputs, and a user journey from opening the repository through reviewing the results.

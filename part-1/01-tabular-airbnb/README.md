# Part 1A — Tabular Dataset: Airbnb Listings

Use this folder for the Airbnb tabular-data study. The implementation may be completed in Google Colab or as a standalone notebook, but the executed artifact should be committed under `notebooks/`.

## Planned deliverables

- Executed EDA, preprocessing, clustering, anomaly-handling, feature-selection, and AutoViML notebook.
- Visualizations and exported figures.
- A short findings report.
- Dataset source and data dictionary.
- Reproducibility notes and environment requirements.

## Folder map

- `data/raw/` — local raw data only; do not commit large files.
- `data/processed/` — generated data products, preferably reproducible rather than committed.
- `notebooks/` — executed Colab export or standalone notebook.
- `src/` — optional reusable cleaning, feature, and modeling code.
- `figures/` — exported plots.
- `reports/` — dataset report and model summary.
- `artifacts/` — tables, metrics, and other supporting outputs.
- `videos/` — link and outline for the walkthrough video.

# Part 1 — EDA, Visualization, Data Preparation, and AutoML

This part contains two independent dataset studies. Each study should include an executed Colab notebook or standalone notebook, saved visual artifacts, a concise report, and a detailed video walkthrough.

## Required workflow for each dataset

1. Dataset source, problem framing, assumptions, and data dictionary.
2. Initial data audit: shape, types, duplicates, missingness, invalid values, and target definition.
3. Manual EDA and visualizations with written insights.
4. Cleaning, data imputation, encoding, scaling, transformations, and feature construction.
5. Clustering and anomaly detection/elimination, with the method and impact documented.
6. Feature selection and leakage checks.
7. AutoML experiments using AutoViML, model comparison, evaluation metrics, and limitations.
8. Final conclusions and reproducibility notes.

## Dataset tracks

- [Tabular — Airbnb listings](./01-tabular-airbnb/README.md)
- [Time series — Metro Interstate Traffic Volume](./02-timeseries-traffic-volume/README.md)

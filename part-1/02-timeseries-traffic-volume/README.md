# Part 1B — Time-Series Dataset: Metro Interstate Traffic Volume

Use this folder for the time-series study. The implementation may be completed in Google Colab or as a standalone notebook, but the executed artifact should be committed under `notebooks/`.

## Planned deliverables

- Executed time-series EDA, preprocessing, clustering, anomaly-handling, feature-selection, and AutoViML notebook.
- Time-based visualizations and exported figures.
- A short findings report describing temporal patterns and modeling results.
- Dataset source, time granularity, and data dictionary.
- Reproducibility notes and environment requirements.

## Folder map

- `data/raw/` — local raw data only; do not commit large files.
- `data/processed/` — generated data products, preferably reproducible rather than committed.
- `notebooks/` — executed Colab export or standalone notebook.
- `src/` — optional reusable time, feature, and modeling code.
- `figures/` — exported plots.
- `reports/` — time-series report and model summary.
- `artifacts/` — tables, metrics, and other supporting outputs.
- `videos/` — link and outline for the walkthrough video.

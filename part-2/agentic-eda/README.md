# Agentic EDA Workflow

This folder contains the Part 2 agent-assisted exploratory analysis.

## Folder map

- `notebooks/` — any executed notebook or exported agent-analysis session.
- `prompts/` — prompts, task instructions, and agent configuration notes.
- `artifacts/` — agent-generated tables, charts, summaries, and exports.
- `screenshots/` — screenshots that document the agent workflow when useful.
- `reports/` — reviewed findings, validation notes, and limitations.
- `videos/` — detailed walkthrough outline and supporting narration notes.

## Suggested analysis record

For each agent run, record the date, tool/version, input files, prompt, generated output, human verification performed, corrections made, and final conclusion.
